# Gen1 Modern UI v0.6.4

This patch fixes nested rich-screen navigation in floating layouts.

Party **STATS** and Pokédex **DATA** now render their dedicated Summary and
DexEntry presenters when opened above the Party or Pokédex list. Previously,
every state above the first was treated as a generic modal, so rich screens
could become an empty “Nothing here” card or leave the parent screen visible
while input moved to the hidden child state.

Only true modal layers—side menus, generic lists, choices, quantities, and
dialogue—use the compact modal renderer. Full rich screens retain their own
layout and live data while remaining stack-compatible with other mods.

## Compatibility

- Requires gen1recomp v0.1.51 or newer.
- Compatible with later 0.x and released 1.x builds in the manifest range.
- Useful Dex, Gen 3 Box, sprite replacement packs, and other supported mods
  retain their existing live data and artwork.
- Battle presentation remains WIP and disabled by default.

## Install

Download `gen1_modern_ui-0.6.4.zip` from the release, open gen1recomp's
**Mods → Import mod .zip** action, and select the archive. The launcher handles
extraction; manual unpacking is not required. Enable **Gen1 Modern UI** under
the **UI** section if needed.
