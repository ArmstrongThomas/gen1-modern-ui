# Gen1 Modern UI v0.7.6

## Highlights

- Changed the experimental **PIXEL ART FONT** setting to default off on new
  installs while retaining Plain Pixel as an opt-in multilingual font.
- Changed experimental **TOUCH / CLICK UI** and **DRAG UI PANELS** to default
  off on new installs. Panel dragging now clearly requires the pointer layer.
- Replaced the dialogue continuation `v` with a compact, right-aligned
  three-dot cue (`...`). Dedicated list scroll arrows remain unchanged.
- Added semantic RBY MMO profile and rank presenters, including guarded
  support for the mod's public player/card and leaderboard payloads.
- Added RBY MMO Town Map party integration using the mod's public party and
  roster exports, so a remote party member appears at their current city on
  the modern map with their selected sprite and display name without taking
  over MMO navigation or callbacks. The selected location also lists players
  who are there.
- Added selected-character artwork to RBY MMO profile and rank presenters by
  cropping the host sprite catalog's front-facing 16x16 pose.
- Pinned Start-menu mod entries now flush immediately to the active save and
  refresh from the current save bucket after reloads.
- Normalized RBY MMO naming-page `123` / `ABC` switch labels so the modern
  naming screen shows the actual case action and keeps a stable footprint
  between uppercase and lowercase pages.

## Compatibility

The release remains visual-first and targets gen1recomp `>=0.1.51 <2.0.0`.
Existing saved preferences remain respected; these safer defaults primarily
affect new installs and missing option values. Keyboard/controller navigation
and the system-font fallback remain available.

## Quick start

1. Download `gen1_modern_ui-0.7.6.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
