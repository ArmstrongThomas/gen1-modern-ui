# Gen1 Modern UI v0.6.8

## Highlights

- Added a compatibility adapter for the released LinkState screens: LAN,
  online, tournament, connection, trade, and link-battle handshakes now use a
  modern, responsive presentation without taking over networking or input.
  Address/code entry shows the active digit slot and keeps the fixed UDP port
  visibly separate from the editable host address.
- Fixed the title-screen main menu fallback on clients that do not expose the
  optional state-decoration hook. The native title rows are suppressed only
  when the modern stack is complete, while the title artwork remains intact.
  While open, the whole title canvas now receives one uniform grayscale
  treatment instead of the native menu's partial palette zone.
- Added PokePCFollowers compatibility. Its six-frame `follower_###.png`
  sheets are cropped to a proper 16px nearest-neighbor frame instead of
  rendering as narrow slivers or stacked previews.
- Made modern dialogue panels content-sized: normal two-line TextBox messages
  stay compact, while richer page models can expand up to five wrapped lines
  and a readable prompt area.
- Reorganized added Start-menu entries under **MOD MENUS** without hiding
  anything: the grouped list always contains every compatible mod entry,
  including pinned rows. Press **SELECT** on a highlighted entry to pin or
  unpin it, with a visible **PINNED** marker when it is promoted to Start.
- Added direct Start-menu access to the same categorized **UI SETTINGS**
  manager used by the mod manager, so Appearance, Navigation, Presenters, and
  Advanced options stay consistent regardless of how the screen is opened.
- Improved compatibility with third-party `OptionRows`-style menus and
  tightened minimal/landscape layouts so short panels do not become oversized
  banners while long labels remain readable.
- Reorganized Gen1 Modern UI settings into expandable Appearance, Navigation,
  Presenters, and Advanced categories. Existing option keys and saved values
  remain unchanged; the legacy desktop-floating row is retained for migration
  but hidden from the normal list.

## Quick start

1. Download `gen1_modern_ui-0.6.8.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm. The launcher installs it automatically; no
   manual extraction is required.
4. Enable **Gen1 Modern UI** under the **UI** section if needed, then restart
   when prompted.

The mod targets gen1recomp `>=0.1.51 <2.0.0` and remains visual-only: the game
continues to own state, callbacks, networking, and input.
