# Gen1 Modern UI v0.7.8

## Highlights

- Added an optional Start Menu party quick view for floating and adaptive
  layouts, showing each party member's nickname, level, and current HP.
- Added a side-menu inset setting in 10% steps for bringing floating menus
  toward the center on ultrawide displays.
- Kept the quick view disabled by default and informational-only so the game's
  existing navigation and callbacks remain unchanged.
- Kept the full Trainer Card profile with portrait, Trainer ID, money, play
  time, and badge progress.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
State transitions, callbacks, networking, and keyboard/controller input remain
owned by the game and third-party mods. Unknown or custom screens retain the
classic fallback.

## Quick start

1. Download `gen1_modern_ui-0.7.8.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
