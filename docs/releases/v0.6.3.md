# Gen1 Modern UI v0.6.3

This patch fixes the floating/world-visible data screens that could briefly
disappear when **HIDE ORIGINAL UI** was enabled. Party **STATS** pages and
Pokédex entry pages now wait for their live Pokémon record before the classic
canvas is suppressed. Newly pushed screens are synchronized immediately on
clients exposing the screen lifecycle event, while older clients retain the
per-step compatibility sweep.

If a third-party screen wrapper is still initializing or exposes an unexpected
data shape, the original page remains visible as a safe fallback instead of
leaving a blank floating frame. Full-screen layout behavior is unchanged.

## Compatibility

- Requires gen1recomp v0.1.51 or newer.
- Compatible with later 0.x and released 1.x builds in the manifest range.
- Useful Dex, Gen 3 Box, sprite replacement packs, and other supported mods
  continue to provide their live data and artwork.
- Battle presentation remains WIP and disabled by default.

## Install

Download `gen1_modern_ui-0.6.3.zip` from the release, open gen1recomp's
**Mods → Import mod .zip** action, and select the archive. The launcher handles
extraction; manual unpacking is not required. Enable **Gen1 Modern UI** under
the **UI** section if needed.
