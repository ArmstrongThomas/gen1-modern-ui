# Gen1 Modern UI v0.7.4

## Highlights

- Added theme-driven panel framing with selectable **UI FRAME STYLE** options
  for authored theme, pixel, soft, and plain treatments.
- Added three selectable hand-authored nine-slice PNG frame assets at
  `assets/pixel_frame1.png`, `assets/pixel_frame2.png`, and
  `assets/pixel_frame3.png`, replacing the generated placeholder while
  retaining crisp corners and repeating edges.
- Added **PIXEL FRAME SCALE** with exact 1X–4X nearest-neighbor multipliers so
  small authored frame pixels remain visible at high-resolution UI sizes.
- Added **PIXEL FRAME** selection to choose among the three shipped borders.
- Added frame insets, margins, and shadows so decorative borders stay outside
  panel content and nested cards remain readable at larger UI scales.
- Stabilized dialogue panel sizing during typewriter reveal and removed the
  temporary hold-button speed-up hint from dialogue cards.
- Added archive, asset-mount, and visual regression coverage for themed frames.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
State transitions, callbacks, networking, and keyboard/controller input remain
owned by the game and third-party mods. Unknown or custom screens retain the
classic fallback.

## Quick start

1. Download `gen1_modern_ui-0.7.4.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
