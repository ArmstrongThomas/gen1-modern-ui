# Gen1 Modern UI v0.7.3

## Highlights

- Made Party, PokÃ©dex data/stats, Bag, Shop, item-detail, and dialogue cards
  content-sized, with narrower data pages that avoid oversized empty panels.

- Replaced essential shop, Bag, and item-detail ellipsizing with measured
  multi-line wrapping, including long move names, descriptions, prices, and
  other localized detail strings.
- Rebalanced Shop and Bag columns so short item lists do not consume the full
  rich-panel width while the detail column receives useful reading space.

- Added `AUTO` choices for UI SCALE and FONT SCALE. AUTO resolves a bounded
  responsive size from the safe window viewport so larger windows can use more
  readable panels and text without requiring a manual percentage.

- Fixed minimal UI panels retaining reference-width ceilings after UI/font
  scaling, which could clip longer labels and value columns.
- Made rich presenter width budgets account for the larger of UI scale and
  font scale while still clamping to the safe viewport.
- Standardized nested quantity, choice, and action dialogs across Pokédex,
  shops, Bag, Party, and other presenters with centered placement and a shared
  dimmed-parent treatment.
- Added minimal Bag regression coverage at reference and high readability
  scales on a large desktop viewport.
- Added nested shop, Bag, and Pokédex modal regression shots.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
State transitions, callbacks, networking, and keyboard/controller input remain
owned by the game and third-party mods. Unknown or custom screens retain the
classic fallback.

## Quick start

1. Download `gen1_modern_ui-0.7.3.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
