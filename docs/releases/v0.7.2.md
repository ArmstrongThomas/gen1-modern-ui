# Gen1 Modern UI v0.7.2

## Highlights

- Fixed a crash path for Nidoran names containing the Gen1 male/female signs.
- Made text truncation UTF-8 character-safe so multi-byte names are never cut
  into invalid strings before LÖVE measures or renders them.
- Added readable `NIDORAN M` / `NIDORAN F` fallbacks when the overlay font lacks
  the gender glyphs.
- Added normal, high-scale, portrait, and landscape Nidoran regression shots.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
State transitions, callbacks, networking, and keyboard/controller input remain
owned by the game and third-party mods. Unknown or custom screens retain the
classic fallback.

## Quick start

1. Download `gen1_modern_ui-0.7.2.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
