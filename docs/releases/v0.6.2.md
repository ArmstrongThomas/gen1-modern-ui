# Gen1 Modern UI v0.6.2

This patch makes the floating presentation work for opaque engine screens.
When **LAYOUT STYLE** is **FLOATING** (or **ADAPTIVE** on a new install), the
mod temporarily lets eligible modernized screens draw over the already-rendered
world instead of revealing a black canvas behind them. **FULL SCREEN** restores
the themed backdrop presentation.

## Highlights

- Floating Party, Pokédex, Trainer Card, PC, Bag, and other supported rich
  screens now preserve the rendered overworld behind their modern panels.
- The original state opacity is restored automatically when Full Screen,
  classic fallback, a disabled presenter, or a custom draw is active.
- Added regression coverage for opaque Bag and Party states and clarified the
  layout behavior in the handoff and packaged mod README.

## Install

Download `gen1_modern_ui-0.6.2.zip` from the release, open gen1recomp's
**Mods → Import mod .zip** action, and select the archive. The launcher handles
extraction; manual unpacking is not required.

Requires gen1recomp v0.1.51 or newer. Battle presentation remains WIP and
disabled by default.
