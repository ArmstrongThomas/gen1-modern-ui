# Gen1 Modern UI v0.8.4

This maintenance release tightens the optional battle UI integration and keeps
the native battle presentation safe while the battle system remains WIP.

## Highlights

- Hardened the opt-in 2D battle presenter so status cards, overlays, messages,
  and action panels only render for the active battle state.
- Preserved native battle child screens, intro flows, animations, and source
  mod behavior whenever Battle UI is disabled.
- Improved battle card sizing and placement across the supported battle layouts
  without enabling the experimental battle overrides by default.
- Improved palette-aware handling for custom/unique menu icon assets.
- Added development-engine compatibility for `0.0.0-dev` while retaining the
  released `>=0.1.51 <2.0.0` compatibility range.
- Synchronized the compatibility and handoff documentation with the current
  battle WIP/default-off policy.

## Compatibility

The release remains visual-first and targets gen1recomp
`0.0.0-dev || >=0.1.51 <2.0.0`. State transitions, callbacks, networking,
battle logic, and source-mod validation remain owned by the game and source
mods. Unsupported screens retain the native fallback.

Battle UI is experimental and remains disabled by default. The 3D/voxel battle
integration is not enabled unless the user explicitly opts into the WIP
presenter and the host/source-mod hooks required by that presentation are
available.

## Quick start

1. Download `gen1_modern_ui-0.8.4.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
