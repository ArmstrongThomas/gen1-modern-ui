# Gen1 Modern UI v0.7.1

## Highlights

- Rich presenters now scale their height budgets with the active UI/font
  readability scale on large safe viewports, revealing more rows instead of
  stopping at the reference-window height cap.
- Compact and minimal presenters retain their content-sized behavior, while
  all expanded panels remain clamped to the safe viewport.
- Horizontal YES/NO layouts now accept LEFT/RIGHT as aliases for UP/DOWN,
  preserving the released ChoiceBox selection and callback behavior.
- Added large-desktop shop and horizontal-choice regression coverage.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
State transitions, callbacks, networking, and keyboard/controller input remain
owned by the game and third-party mods. Unknown or custom screens retain the
classic fallback.

## Quick start

1. Download `gen1_modern_ui-0.7.1.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
