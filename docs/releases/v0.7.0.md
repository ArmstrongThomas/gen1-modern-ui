# Gen1 Modern UI v0.7.0

## Highlights

- Added independent **UI SCALE** controls from 75% to 150% in 5% steps.
- Added independent **FONT SCALE** controls from 80% to 200% in 5% steps.
- Added **DIALOGUE TEXT SCALE** presets from Inherit through 200% for
  dialogue, choices, quantities, and confirmation prompts.
- Applied scaling before measurement and layout, with cached effective fonts
  and theme metrics so larger text raises row minimums instead of blurring a
  completed canvas.
- Added live two-line generic-row reflow and long-word wrapping while keeping
  third-party row descriptors and callbacks untouched.
- Kept dialogue typewriter state engine-owned; the modern presenter wraps only
  the currently revealed text.
- Exported `scaleTokens` and `getScaleTokens()` through the public data-only
  theme API.
- Added scale smoke coverage for 80%, 100%, 125%, 150%, and 200% font cases
  across portrait and landscape test viewports.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
State transitions, callbacks, networking, and keyboard/controller input remain
owned by the game and third-party mods. Unknown or custom screens retain the
classic fallback.

## Quick start

1. Download `gen1_modern_ui-0.7.0.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
