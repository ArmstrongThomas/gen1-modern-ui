# Gen1 Modern UI v0.8.0

## Highlights

- Added the versioned `mod.exports.gen1ModernUi` compatibility contract.
- Added adapter validation, namespaced registration, source-owned semantic
  actions, error isolation, reload/disable invalidation, and conservative
  vanilla fallback.
- Added public source-mod theme and pixel-frame registration. Source assets use
  the shared nearest-neighbor nine-slice renderer with repeating edges,
  integer pixel scaling, and the seven-pixel authored inset.
- Added preferred `screen.render_visible` suppression with the released
  `render.compose` fallback for older hosts.
- Added a source-mod adapter template and updated the compatibility API,
  interoperability audit, handoff, and 1.0 roadmap documentation.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
Models are read-only; source mods retain state transitions, callbacks,
networking, and semantic input ownership. Custom third-party drawing callbacks
are not accepted. Missing, malformed, unsupported, disabled, or failing
adapters retain the classic UI.
