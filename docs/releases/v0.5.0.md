# Gen1 Modern UI v0.5.0

Gen1 Modern UI 0.5.0 is a responsive, high-resolution presentation layer for
released [gen1recomp](https://github.com/bryanthaboi/gen1recomp) builds. It
keeps the game's state, input ownership, and mod callbacks intact while
giving common screens richer information and layouts that adapt to portrait,
landscape, desktop, and mobile windows.

## Highlights

- **Pokemon Box / Bill's PC:** square responsive grids, active sprite-pack
  artwork, HP/status details, richer selected-Pokemon information, and safer
  withdraw, deposit, release, and party/box navigation.
- **Pokedex:** selected entries can show live names, numbers, seen/owned state,
  descriptions, page controls, and compatible authored artwork without
  forcing the original client layout.
- **Party:** larger sprite previews, HP/status, types, current stats, moves
  and PP, plus a more useful action flow. Party rows continue to come from the
  live game/mod state, so added entries remain visible.
- **Bag and shops:** item quantities and descriptions now share a consistent
  detail card; shops show the base purchase value and the 50% sell value, and
  TM/HM/key-item metadata is shown when available.
- **Trainer, Player PC, dialogue, and choices:** modern cards include Trainer
  ID and other available data, while dialogue, yes/no, quantity, and action
  prompts retain their normal callbacks and timing.
- **Responsive presentation:** portrait and landscape safe areas, square box
  cells, nearest-neighbor/aspect-fit sprites, themeable opaque/glass shells,
  and an optional desktop floating-panel layout.
- **Compatibility:** live rows and active mod assets are read rather than
  copied into replacement menus. Useful Dex, Gen 3 Box, sprite replacement
  packs, inventory/category mods, and future UI entries can coexist; unknown
  screens fall back to the classic UI.
- **Minimal UI:** an option removes optional detail/preview panes for a
  closer-to-original information density while retaining the modern shell and
  responsive controls.

## Install

1. Download `gen1_modern_ui-0.5.0.zip` from the Assets section.
2. In gen1recomp, open **Mods -> Import mod .zip** and choose the archive.
3. Enable **Gen1 Modern UI** under the **UI** section, then restart if the
   launcher asks you to.

The launcher imports the ZIP directly; users do not need to extract it first.
The release requires gen1recomp v0.1.51 or newer and remains compatible with
the released 1.x line.

## Notes

- Battle presentation is still WIP and is disabled by default.
- The **HIDE ORIGINAL UI** option only suppresses classic UI canvases when a
  supported modern presenter owns the screen; unsupported or nested screens
  retain their classic fallback for compatibility.
