# Gen1 Modern UI v0.8.2

This release contains the initial battle presentation work and rendering fixes
added after v0.8.1.

## Highlights

### Battle UI (WIP)

- Added the first modern 2D WIDE battle presentation with live battle scene
  content retained behind the modern interface.
- Added modern enemy and player status cards with HP, level, type, ownership,
  caught indicators, and the player's experience bar when the source data is
  available.
- Added modern action and move-selection menus, item and party overlays, and a
  themed level-up stat card.
- Added support for the white, black, and world battle background choices while
  keeping the battle scene inside the framed presentation surface.
- Battle UI remains WIP and disabled by default. The 2D WIDE battle layout is
  usable with minor known layout and rendering issues; voxel/scene battle modes,
  additional battle screens, and further animation polish remain in progress.

### Rendering and compatibility fixes

- Tightened native battle suppression and compose clipping so native HUD pieces
  do not reappear during HP animations or leak outside the modern battle frame.
- Kept source-owned battle actions, state transitions, animations, and callbacks
  intact while the modern presenter supplies the visual layer.
- Added regression coverage for host `StatBox` suppression, render visibility,
  world-background leakage, and battle-surface boundaries.
- Preserved the existing compatibility framework, theme/frame support, palette-
  aware assets, responsive scaling, and vanilla fallback behavior for unsupported
  screens.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
Battle input, state transitions, callbacks, networking, and animation ownership
remain with the game and source mods. Unsupported battle modes and future
third-party battle screens retain the classic fallback while battle support is
being completed.

## Quick start

1. Download `gen1_modern_ui-0.8.2.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
