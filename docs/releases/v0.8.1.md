# Gen1 Modern UI v0.8.1

This release contains the compatibility and presentation work added after the
published [v0.8.0 release](https://github.com/ArmstrongThomas/gen1-modern-ui/releases/tag/v0.8.0).

## Highlights

### Compatibility foundation

- Added the versioned `mod.exports.gen1ModernUi` contract (`apiVersion = 1`)
  for source-mod-owned screen models, semantic actions, public image catalogs,
  themes, and pixel frames.
- Added adapter discovery through `mod.find(...).exports`, namespaced
  registration, API/model validation, error isolation, and safe cache
  invalidation when mods reload or become disabled.
- Models remain read-only presentation data. Source mods retain ownership of
  callbacks, validation, networking, state transitions, and semantic actions.
- Rejected custom third-party draw callbacks, private-state reach-through, and
  arbitrary file execution. Missing, malformed, unsupported, disabled, or
  failing integrations fall back to vanilla rendering.
- Added preferred `screen.render_visible` suppression with the older
  `render.compose` fallback for hosts without the newer hook.
- Added documented drop-in examples for generic adapters, RBYMMO, Dex Radar,
  OptionRows menus, and Useful Bag.

### Themes, frames, and fonts

- Added source-mod registration for multiple namespaced themes and pixel
  frames, including source-owned PNG/image assets and the shared
  nearest-neighbor nine-slice renderer.
- Preserved integer pixel scaling, repeating edge slices, and the seven-pixel
  authored frame inset for custom PNG borders.
- Added high-contrast **Light** and **Dark** themes and improved text, divider,
  selection, and health-bar colors across the built-in palettes.
- Kept the normal UI font on the lightweight host path and added automatic
  non-Latin Unicode detection. Screens containing Japanese, CJK, Cyrillic,
  Greek, Arabic, emoji, or other non-Latin text automatically use the game's
  Plain Pixel font without adding a large fallback font to the mod package.

### Mod integrations

- Added compatibility coverage and documentation for RBYMMO profile, rank,
  character-selection, map-player, party-marker, portrait, and public profile
  data paths.
- Added compatibility bridges for Gen 3 Box, Useful Dex, Modern Bag/Bag 999,
  Item Shortcut, PC/shop extensions, and Quality-of-Life location banners,
  while preserving their live state and source-owned callbacks.
- Fixed the current standalone Useful Bag integration so its pocketed item
  lists continue using the modern Items/Shop presentation while Useful Bag
  retains pocket switching, sorting, selection, and callbacks.
- Added DV Tracker Summary page support for DV and Stat EXP data, including
  the tracker’s derived HP DV behavior and its `dvs`/`ivs` fallbacks.
- Kept existing Dex Radar support while documenting its adapter migration path
  for future source-owned exports.
- Extended pointer hover/select routing for contract-backed rows while keeping
  source-owned semantic actions and native keyboard/controller behavior intact.

### Documentation and verification

- Added the custom UI/theme API guide, interoperability audit, handoff notes,
  roadmap updates, source-mod templates, and compatibility examples.
- Added contract, Useful Bag shape, suppression, fallback, and malformed-data
  regression coverage to the local test fixtures.
- Added release/package guidance for the multilingual font fallback behavior.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
Source mods retain state transitions, callbacks, networking, and semantic
input ownership. Unsupported future screens remain on the classic renderer.
