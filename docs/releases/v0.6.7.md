# Gen1 Modern UI v0.6.7

## Highlights

- Fixed the title/main-menu black-screen regression. The native title menu is
  suppressed only while the modern presenter is complete; the shared title
  artwork canvas is no longer cleared.
- UI SETTINGS now lives under MOD MENUS by default, keeping the Start menu
  compact as other mods add entries.
- Highlight any row in MOD MENUS and press SELECT to pin or unpin it on the
  Start menu. Pins use stable row IDs when provided and are persisted through
  the mod save store.
- Grouped rows keep their original descriptors, callbacks, ordering, and input
  ownership. Disable START MOD MENUS to restore a flat list.

## Quick start

1. Download `gen1_modern_ui-0.6.7.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive, confirm the import, and enable **Gen1 Modern UI** under
   **UI** if needed. The launcher installs the archive automatically; no manual
   extraction is required.

The mod targets gen1recomp `>=0.1.51 <2.0.0` and remains visual-only: the game
continues to own state, callbacks, and input.
