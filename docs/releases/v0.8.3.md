# Gen1 Modern UI v0.8.3

This stability release fixes the regressions that could make v0.8.2 unusable
with New Game, disabled Battle UI, and several mod/menu combinations.

## Highlights

### New Game and naming fixes

- Restored the complete native Professor Oak introduction, name-choice prompts,
  and naming keyboard instead of partially suppressing them through the modern
  Menu and Dialogue presenters.
- Kept pending native dialogue and choice states visible while the game is still
  populating their content, preventing blank or missing New Game prompts.
- Stopped extending the native naming keyboard when Menu UI is disabled, so
  extra number rows no longer appear or remain navigable off-screen.
- Added lifecycle-safe ownership tracking so nested New Game screens remain
  native even when screen events do not include a game reference.

### Disabled Battle UI now stays disabled

- Prevented the WIP Battle UI from decorating, suppressing, or clearing native
  battle draw paths while its toggle is off.
- Restored any battle wrappers installed earlier in the same session when Battle
  UI is disabled.
- Restored native in-battle Bag, Party, choice, intro, and level-up surfaces when
  the WIP presenter is disabled, including compatibility with DramaticShape's
  voxel battle presentation.
- Battle UI remains WIP, disabled by default, and unchanged as an opt-in preview.

### Mod menu interoperability

- Kept `MOD MENUS` and the modern Mod Manager available when the generic Menu UI
  and Dialogue UI presenters are disabled.
- Made the Mod Manager follow its dedicated setting instead of the generic menu
  presenter toggles.
- Hardened start-menu grouping against mods that clone or replace menu row
  descriptors, fixing interoperability with QoL Toggles, Useful Bag, and similar
  injected menu entries.
- Preserved vanilla start-menu rows while grouping compatible mod-owned entries.

### Regression coverage

- Added coverage for New Game dialogue/name entry, native naming grids, disabled
  battle children, runtime battle-wrapper restoration, Mod Manager ownership,
  and cloned start-menu descriptors.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
State transitions, callbacks, networking, battle logic, and source-mod validation
remain owned by the game and source mods. Unknown or unsupported screens retain
the native fallback.

Battle UI remains experimental and disabled by default. v0.8.3 specifically
ensures disabling it restores the host and third-party battle presentation
without leaving Modern UI wrappers active.

## Quick start

1. Download `gen1_modern_ui-0.8.3.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
