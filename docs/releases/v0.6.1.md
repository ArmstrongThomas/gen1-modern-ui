# Gen1 Modern UI v0.6.1

This maintenance release improves readability on narrow windows and adds a
small touch-friendly navigation shortcut.

## Highlights

- Option rows now measure label/value pairs together. Long values such as
  `Classic Mono` stay visible whenever the panel can accommodate them, and
  narrow layouts truncate without overlapping the neighboring column.
- Landscape panels may grow to the measured content width instead of being
  forced under an overly small global cap. Floating side menus remain compact
  until their labels actually require more room.
- New **START MENU FAST JUMP** option (on by default): tap left/right on the
  engine touch d-pad to move five Start-menu rows at a time. Keyboard and
  controller left/right use the same shortcut; up/down, A, B, and callbacks
  remain owned by the original StartMenu state.
- Press **SELECT** on a Gen1 Modern UI option to read its brief description;
  **SELECT**, **A**, or **B** closes the help card.
- Existing adaptive/floating, Minimal UI, opacity, sprite, theme, and
  third-party menu compatibility behavior is unchanged.

## Install

Download `gen1_modern_ui-0.6.1.zip` from the release, open gen1recomp's Mods
tab, choose **Import mod .zip**, and select the archive. The launcher handles
extraction; do not unpack the ZIP manually.

Requires gen1recomp v0.1.51 or newer. Battle presentation remains WIP and
disabled by default.
