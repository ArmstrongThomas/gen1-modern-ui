# Gen1 Modern UI v0.7.7

## Highlights

- Improved Plain Pixel rendering when **PIXEL ART FONT** is enabled.
- Kept Plain Pixel's 11-row artwork cell separate from its documented 15-point
  raster steps so glyphs remain undistorted rather than being forced through an
  arbitrary 11-point font size.
- Snapped Plain Pixel text origins to the physical render grid, preventing fractional
  responsive layouts from softening or unevenly shifting pixel glyphs.
- Quantized PNG frame panels to the viewport's physical pixel grid and kept
  tiled edges on complete source-pixel blocks, removing fractional corner and
  right/bottom drift at non-integer window scales.
- Applied the engine's active map/species palettes to vanilla Pokédex, party,
  RBYMMO portrait, character-select, and Town Map marker sprites while leaving
  explicitly true-color replacement art untouched.
- Let ordinary multi-line dialogue pages grow into stable readable cards,
  preventing four-line save/NPC messages from racing through a two-line scroll
  window at FAST text speed while preserving intentional continuation pauses.
- Updated the focused font probe and presenter checks to document and validate
  the 11-row / 15-point rendering contract.

## Compatibility

The release remains visual-only and targets gen1recomp `>=0.1.51 <2.0.0`.
State transitions, callbacks, networking, and keyboard/controller input remain
owned by the game and third-party mods. Unknown or custom screens retain the
classic fallback.

## Quick start

1. Download `gen1_modern_ui-0.7.7.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
