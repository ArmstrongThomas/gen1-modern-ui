# Gen1 Modern UI v0.9.0

This feature release establishes a responsive layout system and a public,
additive UI-extension framework so other mods can augment Modern UI screens
without replacing them wholesale.

## Highlights

- Added versioned additive extension points for screen pages, menu actions,
  party-row decoration, icons, overlays, and battle adapters, with native-safe
  fallback behavior for unsupported or incomplete integrations.
- Added copy-ready examples for party-row backgrounds, Trainer Card pages,
  additive extensions, and the separated FelizNavidad-D 3D battle-menu
  integration.
- Added an in-game UI Gallery under **UI Settings → Advanced**. Its named
  specimens exercise every supported presenter kind through production draw
  paths and expose stable IDs for bug reports and extension development.
- Added EMPTY, SPARSE, NORMAL, FULL, and OVERFLOW content profiles plus
  temporary UI-scale, font-scale, and font-family controls. Gallery overrides
  never modify saved settings.
- Added stable XS/S/M/L/XL/BATTLE envelopes, measured interior bounds, overflow
  diagnostics, monitor-safe scale capping, and whole-step Plain Pixel scaling.
  Content changes inside a screen no longer resize its outer envelope.
- Extended UI and manual system-font scaling through 400%. AUTO retains the
  existing curve and text/chrome ratio through 1080p, then grows UI to 200% at
  1440p, 300% at 4K, and 385% on a 5120×2784 safe viewport; system-font AUTO
  may reach 500%. Plain Pixel AUTO remains a whole 1×–4× step. The 2D WIDE
  battle shell now reaches roughly half of a 4K/5K display instead of remaining
  capped at 960×540.
- Balanced dialogue readability presets by scaling text, interior spacing, and
  chrome together. Modern dialogue also reflows legacy `\n`/`\v` placement
  against its real width while preserving typewriter state, continuation
  gates, hard-wrapped tokens, and `\f` page boundaries.
- Added API v2 isolated custom surfaces with virtual coordinates, safe-area
  fitting, frame time/delta, scoped shader/palette/silhouette helpers, virtual
  pointer regions, Gallery fixtures, and transactional native fallback. A
  failed render can never leave the source menu invisible.
- Added v2 structured `custom_fields`, bottom-anchored `footer_lists`,
  `shrink_to_fit` constraints, and data-only `modal_overlay` actions. At the
  minimum pixel-font step, compact reflow prevents impossible content from
  overlapping.
- Capped rich presenter fonts against their actual preset envelope while
  preserving whole Plain Pixel steps. This removes high-scale Party/Pokédex
  header collisions and keeps selected rows below title chrome.
- Reduced the Load Report to a compact stable envelope and removed the stale
  native battle text frame between 2D WIDE actions.
- Standardized the modern 2D battle presenter on one bounded WIDE envelope. In
  portrait, the opponent card occupies its own slot above the renderer and the
  player card remains below it.
- Preserved the post-catch AskName flow as two explicitly modeled screens: the
  nickname dialogue/YES-NO prompt and the NamingScreen reached after YES. The
  modern battle HUD honors the host's intentionally cleared catch field while
  either child screen is open.
- Added the **Leave 3D Battles Alone** ownership setting so voxel battle mods
  can retain their complete interface without Modern UI replacing child HUDs.

## Compatibility

The release remains visual-first and targets gen1recomp
`0.0.0-dev || >=0.1.51 <2.0.0`. State transitions, callbacks, networking,
battle logic, and source-mod validation remain owned by the game and source
mods. Unsupported screens retain the native fallback.

The bundled battle presenter is for 2D battles and remains opt-in. With
**Leave 3D Battles Alone** enabled, detected voxel/3D battle owners keep their
entire battle UI. Third-party extensions are additive and do not require older
custom UIs to migrate.

For visual QA, open **Start → Mod Menus → UI Settings → Advanced → UI
Gallery**. Gallery scale and content overrides are temporary and are discarded
when the gallery closes.

## Quick start

1. Download `gen1_modern_ui-0.9.0.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
