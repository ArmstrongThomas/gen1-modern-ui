# Gen1 Modern UI v0.6.0

This release focuses on making the modern interface feel lighter and more
natural on every screen size. Panels now measure their visible content instead
of reserving large empty regions, and Minimal UI uses compact layouts after its
optional detail panes are removed.

## Highlights

- Adaptive floating layouts now work on desktop and mobile.
- New `LAYOUT STYLE` option: Adaptive, Floating, or Full Screen.
- Landscape panels generally stay within a narrow central reading column while
  gaining the height needed for their content.
- Independent `PANEL OPACITY` and `TEXT / LINE OPACITY` controls.
- Redundant `MENU` and choice headings are removed where context is already
  clear.
- New default-on `START UI SETTINGS` shortcut opens this mod's options from the
  in-game Start menu.
- Minimal UI no longer leaves oversized blank panels after hiding previews and
  detail cards.
- Existing Party, Box, Pokédex, Bag, Shop, Trainer, Summary, dialogue, and
  third-party rows continue to use live game state and callbacks.

## Install

Download `gen1_modern_ui-0.6.0.zip` from the release, open gen1recomp's Mods
tab, choose **Import mod .zip**, and select the archive. The launcher handles
extraction; do not unpack the ZIP manually.

## Compatibility

Requires gen1recomp v0.1.51 or newer. The mod remains visual-only and does not
modify the game executable. Unsupported or custom-drawn screens retain their
classic UI automatically.

Battle presentation remains WIP and disabled by default.
