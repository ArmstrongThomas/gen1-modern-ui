# Gen1 Modern UI v0.6.6

This patch adds compatibility coverage for popular third-party settings
screens that use gen1recomp's public `OptionRows` pattern.

## Highlights

- Run Mode, Shiny Pokémon, and Quality of Life settings now use the modern
  high-resolution presenter instead of the native 160×144 options renderer.
- The adapter reads each screen's current labels and values on every HUD pass,
  so changing a setting or adding a row remains owned by the source mod.
- Manager screens underneath a registered mod-options page are not duplicated
  in floating layouts; the source screen remains responsible for navigation,
  callbacks, and back behavior.
- Unknown custom settings shapes remain on the classic UI through the existing
  conservative fallback path.

## Compatibility

- Requires gen1recomp v0.1.51 or newer.
- Audited mods: [Run Mode](https://github.com/masterwebx/gen1recomp-run-mode),
  [Shiny Pokémon](https://github.com/masterwebx/gen1recomp-shiny-pokemon), and
  [Quality of Life](https://github.com/unxpected-uxp/pokemon-gen1-recomp-mod-qol).
- Battle presentation remains WIP and disabled by default.

## Install

Download `gen1_modern_ui-0.6.6.zip` from the release, open gen1recomp's
**Mods → Import mod .zip** action, and select the archive. The launcher handles
extraction; manual unpacking is not required.
