# Gen1 Modern UI v0.9.2

This remains a retired Gen1-only legacy release. It is a small maintenance
update for users who still rely on Gen1 Modern UI while Gen1 Clean UI is under
development.

## Changes

- Bumped the legacy package to 0.9.2 while keeping it explicitly Gen1-only and
  incompatible with `gen1_clean_ui`.
- Declared the existing `engine_internals` and `network` sandbox permissions so
  the legacy screen and link adapters remain drop-in compatible with current
  gen1recomp mod loading.
- Documented the sandbox compatibility boundary and retained the existing
  source-owned presentation compatibility work from PR #13.

No new UI development is planned for this retired project. New work continues
in Gen1 Clean UI.
