# Gen1 Modern UI v0.9.1

This is the final, retired release of Gen1 Modern UI.

## Changes

- Declares explicit Gen1-only support with `"games": ["gen1"]`.
- Conflicts with `gen1_clean_ui` so the legacy and replacement presenters
  cannot accidentally suppress the same interface.
- Restores a tall, narrow `440x560` NAV envelope for Start and MOD MENUS,
  allowing at least eight ordinary entries before scrolling at the normal
  desktop density.
- Keeps the existing V1/V2 compatibility API and documentation frozen for
  mods that still depend on this release.

The release scope is exclusively Gen1. New development continues in the
separate Clean UI repositories.
