# Gen1 Modern UI v0.6.5

This patch polishes Minimal UI layouts and removes the duplicate native title
menu on the game’s main screen.

## Highlights

- Minimal Party, PC, Bag, Shop, and context-list presenters now measure their
  visible labels and values, avoiding oversized cards and large unused regions.
- Added **START MOD MENUS**, which groups menu rows appended by other mods under
  one entry so a heavily customized Start menu stays readable. It is enabled by
  default and can be disabled from Gen1 Modern UI options.
- The title-screen artwork remains on the shared classic canvas while the
  native Continue/New Game/Option menu area is cleared before the modern
  floating menu is drawn. Custom title menus and unsupported overlays still
  fall back safely.
- Added regression coverage for selective title-canvas clearing and preserved
  title artwork.

## Compatibility

- Requires gen1recomp v0.1.51 or newer.
- Compatible with later 0.x and released 1.x builds in the manifest range.
- Useful Dex, Gen 3 Box, sprite replacement packs, and other supported mods
  retain their live data and artwork.
- Battle presentation remains WIP and disabled by default.

## Install

Download `gen1_modern_ui-0.6.5.zip` from the release, open gen1recomp’s
**Mods → Import mod .zip** action, and select the archive. The launcher handles
extraction; manual unpacking is not required. Enable **Gen1 Modern UI** under
the **UI** section if needed.
