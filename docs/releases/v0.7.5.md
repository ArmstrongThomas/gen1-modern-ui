# Gen1 Modern UI v0.7.5

## Highlights

- Added touch and mouse pointer support through gen1recomp's `input.pointer`
  hook and source-safe `mod.input` actions.
- Mouse hover now follows the live modern cursor without activating rows.
- Modern rows, dialogue cards, choices, and quantity prompts can be tapped;
  taps select the live state and use its normal A action path.
- Touch-dragging overflowing lists scrolls their live state, while panel chrome
  remains available for moving the entire panel.
- Desktop left-click maps to `A` and right-click maps to `B`, including outside
  modern panels; dragging suppresses the release action.
- Categorized Gen1 Modern UI settings rows support mouse hover and activation
  through their live manager cursor.
- Fixed Manager options hover resetting to the first row through the host's
  non-options `snapCursor` helper.
- Added direct hover/click targets for PC box grid cells and Manager YES/NO
  confirmations.
- Added contextual desktop controls for arrows, **SELECT**, and **START** on
  screens that expose those actions; native TouchControls still take priority.
- Added all-four-arrow controls to Link code/address editing while making
  waiting/status rows deliberately non-interactive.
- Stabilized drag scrolling with row-sized hysteresis so large shop and item
  lists follow the pointer predictably.
- Added multi-touch and mouse drag capture for modern panels, with normalized
  per-screen-family positions saved through the mod save store.
- Added **TOUCH / CLICK UI** and **DRAG UI PANELS** settings, both enabled by
  default on new installs and independently disableable.
- Virtual TouchControls retain first refusal, cancelled pointer lifecycles
  clean up safely, and keyboard/controller navigation remains unchanged.
- Hardened rapid clicking: only the top layer is interactive, press/release
  must match one live target, in-place screen changes invalidate captures,
  Party/Manager prompts block their parents, and empty rows cannot fire A.
- Fixed a queued-input source bug that could leave DOWN held after navigating
  a horizontal YES/NO card with RIGHT. L/R now uses atomic source-safe taps.
- Added a default-on **PIXEL ART FONT** toggle using gen1recomp's bundled Plain
  Pixel face across all modern presenters. Raster sizes now follow its native
  15-pixel grid with nearest filtering, and normalized line metrics prevent
  the multilingual face from appearing vertically stretched or inflating UI
  panels. The system face remains a safe host and missing-glyph fallback.
- Changed first-run appearance defaults to **Classic Mono**, **PIXEL** frame
  style, and **FRAME 2**.

## Compatibility

The release remains visual-first and targets gen1recomp `>=0.1.51 <2.0.0`.
Hosts that do not expose the new pointer/input hooks fall back to the previous
keyboard/controller behavior. Hosts without the bundled Plain Pixel asset use
the system font. Atomic box transfer and other custom replacement actions that
lack public state remain future adapter work.

## Quick start

1. Download `gen1_modern_ui-0.7.5.zip` from this release.
2. In gen1recomp, open **Mods** and choose **Import mod .zip**.
3. Select the archive and confirm the import.
4. Enable **Gen1 Modern UI** under **UI** if needed, then restart when prompted.
